# 🐍 Pixel Snake

A retro-inspired Snake game built with Python and Pygame.

## 🎮 Features

- Pixel-art inspired design
- Animated Snake on the main menu
- Background music
- Sound effects
- Pause and resume system
- High score saving
- Difficulty selection
- Game Over screen
- Restart and return-to-menu options

## 🕹️ Controls

| Key | Action |
|---|---|
| ↑ ↓ ← → | Move the Snake |
| SPACE | Pause / Resume |
| ENTER | Select Menu |
| R | Restart after Game Over |
| Q | Return to Menu |
