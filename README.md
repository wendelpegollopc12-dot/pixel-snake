# 🐍 Pixel Snake

A retro-inspired Snake game built with Python and Pygame.

## 🎮 Features

- Pixel-art inspired design
- Animated menu snake
- Background music
- Sound effects
- Pause and resume system
- High score saving
- Difficulty selection
- Game Over screen

## 🕹️ Controls

- **Arrow Keys** — Move the snake
- **Space** — Pause / Resume
- **Enter** — Select
- **Q** — Return to Menu
- **R** — Restart

## 🛠️ Built With

- Python
- Pygame
